# WEEK-3
SQL project based on a fictional Flipcart e-commerce product catalogue. Covers MySQL fundamentals, including SELECT, filtering, sorting, DISTINCT, aggregate functions, GROUP BY, HAVING, NULL handling, CASE expressions, and practical product data analysis.

## Flipcart E-Commerce SQL Project

SQL project based on a fictional Flipcart e-commerce product catalogue containing product information such as product name, category, brand, price, stock quantity, active status, ratings, launch date, and discount percentage.

## Topics Covered

* SELECT statements
* WHERE filtering
* ORDER BY sorting
* IN, BETWEEN and LIKE operators
* DISTINCT
* Aggregate functions: COUNT, SUM, AVG, MAX and MIN
* GROUP BY
* HAVING
* NULL handling
* COALESCE
* CASE WHEN
* Data classification using price tiers
* Product and category analysis

## Project Structure

* `flipcart_setup.sql` – Database setup, dataset, and SQL queries
* Section A – SQL theory questions
* Section B – SQL output prediction
* Section C – Applied SQL queries

## Objective

The objective of this project is to practice MySQL concepts and apply SQL queries to analyse an e-commerce product catalogue, including product categories, prices, stock levels, ratings, active products, and premium products.

## Skills Demonstrated

MySQL | SQL Queries | Data Filtering | Aggregation | Grouping | NULL Handling | Conditional Logic | Data Analysis
